# Tic-Tac-Toe
A classic two-player Tic-Tac-Toe game built with Python and tkinter.
## Features
- User-friendly graphical interface (3x3 clickable grid)
- Two players alternate placing X and O
- Automatic win / draw detection with winning-line highlighting
- Cumulative scoreboard across rounds
- "New Game" button to start the next round (scores are preserved)
## Requirements
- Python 3.7+
- tkinter (bundled with most Python installations)
