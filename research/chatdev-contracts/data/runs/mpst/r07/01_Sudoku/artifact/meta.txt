2 **why other modalities fall short**:

   - **dashboard**: designed for real-time information display, not interactive gameplay

3 **application advantages**:
   - python-based applications can implement the complete 9x9 grid with clean visual rendering (eg, via pygame or tkinter)
   - full support for keyboard/mouse input into specific cells
   - real-time mistake detection against row, column, and 3x3 subgrid rules
   - automatic win-condition detection when the puzzle is correctly completed
   - can be easily run locally without dependencies on browsers or network access
