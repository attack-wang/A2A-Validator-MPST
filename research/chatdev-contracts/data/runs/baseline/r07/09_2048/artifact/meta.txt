- dynamic 4x4 grid rendering with tile merging logic
- random tile generation after each move
- live score tracking and highest-tile display
- game-over detection when no moves remain

**evaluating the modalities:**

static formats (image, document, powerpoint, excel, pdf, mind map) are immediately ruled out — they cannot deliver the interactivity and real-time game logic this task demands dashboard is optimized for monitoring real-time data, not for gameplay

that leaves two strong candidates:

1 **application (python, eg, pygame):** offers full control over the game loop and desktop-native feel however, it requires users to have a python environment and dependencies installed, which creates friction for a casual puzzle game

2 **website (html/css/javascript):** runs instantly in any modern browser with zero installation arrow-key events, css grid layouts, and smooth tile-merge animations are natively supported a single html file works across windows, macos, and linux, and is trivially shareable

**my recommendation: website** for a casual, viral-style puzzle game like 2048, frictionless accessibility is the key to product success a single html file delivers the complete experience — keyboard controls, merging animations, score and highest-tile tracking — without any setup barrier for the user
