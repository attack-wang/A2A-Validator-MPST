# Trivia Quiz
A command-line trivia quiz application written in Python.
## Features
- Multiple-choice and short-answer questions
- Configurable question banks (JSON files)
- Topic filtering and question count selection
- Score tracking with percentage and per-topic breakdown
- Optional answer review after the quiz
- Optional immediate feedback mode
## Requirements
- Python 3.6+ (no third-party dependencies)
