A new puzzle is generated daily.

**my recommendation: website (html)**

here's my reasoning:

- **rich interactivity**: html + css + javascript perfectly handles word selection, deselection, shuffle animations, and instant visual feedback — all core mechanics of this puzzle game
- **zero installation barrier**: players can open the game directly in any browser with a single click no python environment, no dependencies — critical for a casual daily puzzle game where friction kills engagement
- **daily puzzle support**: javascript can generate date-seeded puzzles deterministically, and localstorage can persist each day's progress and streak
- **visual polish**: css makes implementing the color-coded difficulty system, grid layout, and smooth transitions straightforward and beautiful
- **easy distribution**: a single html file can be shared via email, hosted anywhere, or played offline

while application (python) is also capable of building games, it requires environment setup and lacks the seamless accessibility that a daily-habit puzzle game demands
