**my recommendation: application (python)**

here's my reasoning:
- the customer explicitly asked for a "program" with interactive features — users need to enter answers, which requires real-time input handling that static formats (pdf, document, powerpoint) cannot provide
- score tracking and logic flow (question sequencing, answer validation, final tally) demand executable software logic, which the application modality fully supports via python
- configurable question banks can be elegantly implemented as external files (eg, json or text files) that the application loads, giving users flexibility to customize their own quizzes
- the option to display correct answers after the quiz is a simple configuration toggle, easily handled in an application
- a command-line or gui-based python application is robust, realizable, and directly matches the "quiz program" nature of this task

while a website could theoretically support interactivity via javascript, the term "program" in the customer's request, combined with the need for configurable local question banks, points more naturally to a standalone application
